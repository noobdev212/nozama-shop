## About The Project

Nozama at its core, is an e-commerce shop that focuses on selling digital products. To give more context, this is an old group project of mine that I wanted to build from scratch using a different tech stack. My vision for the project is to make a platform for any digital assets that can be sold online in an Amazon like platform. Think of it like Payhip Marketpalce as a good reference as to what I invision. Keep it mind though that this is currently a side project of mine and as part of my hobby. Therefore, after releasing `v1.0`, upcoming updates would be stagnated. Lastly, if you wish to use this as a template, feel free to do so.

## Getting Started

As mentioned above, Nozama is built using the Django framework specifically Python 3.14.7 and Sqlite 3.53.4. To run the project, simply follow the steps below containing the complete process from installation to execution.

### Installation

1. Make sure to install `sqlite3` and `python3` before proceeding to the next.
2. Clone the repo
   ```sh
   git clone https://github.com/noobdev212/nozama-shop.git
   ```
3. Create and activate virtual environment.
4. Execute command `pip install -r requirements.txt`.
5. Run the application `python manage.py runserver`.
6. Open the address provided by django.

## Contributing

If you want to join us and become a contributer for Nozama Shop. Feel free to take on an open issue and follow these steps to be align with us:

1.) Fork the repository.
2.) Take on any of the open issues that is currently in new status.
3.) Create a branch with the following format: `<Issue No.>/<Title of Issue>` an example will be `012/example-issue`.
4.) Use `git add` and `git commit -m "Example message in present tense"` once completed.
5.) Push the branch to repository and open a pull request.
